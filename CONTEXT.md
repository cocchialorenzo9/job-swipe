# Job Swipe glossary

**Board**
One person's private job feed in their Claude account. It holds their jobs, swipes, notes, CV details and tailored CVs. Each person has their own board; nobody shares one.

**Board spec**
The written description of a board: what it shows, what it looks like, what it stores and how it behaves. Claude builds each person's board from it at set-up time. Two boards built from the same spec look and behave the same, though they are not the same file.

**Board version**
The version of the board spec a board was built from. A board stays on its version until its owner chooses to rebuild it. Boards made before the board spec existed count as 0.3.x.

**Reference board**
The board the board spec was written from. It lives in the repository, is never shipped, and is what the spec's screenshots are taken from. If the reference board and the board spec disagree, the spec is right.

**CV details**
The facts about a person that Claude builds tailored CVs from. Also called the master CV.

**Job spec**
What Claude writes down about one liked job so it can tailor a CV to it.

**Tailored CV**
A one-page CV made for one liked job from the CV details and that job's spec. It is kept for 7 days.

**Listed**
Accepted into the Claude plugin directory, where people can find and install Job Swipe.
_Avoid_: "verified". That is a status an organization holds, not something a plugin earns.

**Verified organization**
A publisher status in the Claude plugin directory. Only Verified organizations may ship scripts and other code files in a plugin.
